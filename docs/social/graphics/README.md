# Client+ social graphics

Square 1080×1080 PNG cards for the Client+ Case Management Facebook Page. They use the public site palette (paper `#FBF9FA`, ink `#17151C`, accent `#B0174F`) and the Client+ wordmark. No URLs appear on any image. Product cards have a small `(775) 722-7725` footer; holiday and thank-you cards use the Page name instead.

These files are for Cofounder to attach when scheduling or updating posts. Nothing here has been posted, boosted, or spent.
